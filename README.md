# 영어 공부 기록

코덱스로 토익 듣기·읽기 기초와 영어 코딩 문서 이해를 연습하는 개인 학습 저장소입니다.

## 공부 이어가기

이 저장소를 컴퓨터에 내려받아 코덱스에서 해당 폴더를 열고 다음과 같이 요청합니다.

> AGENTS.md와 PROGRESS.md를 읽고 다음 수업을 시작해 줘. 지난 오답을 답 없이 복습한 뒤 새 내용을 진행해 줘.

채팅 없이 공부할 때는 해당 일차의 REVIEW.md를 먼저 풀고, LESSON.md에서 정답과 해설을 확인합니다.
듣기는 실제 MP3가 제공된 경우에만 음성 파일로 연습합니다. 현재 MP3 파일은 없습니다.

## 기록 위치

- [현재 진도](PROGRESS.md): 다음 수업, 오답, 복습 일정
- [학습 지침](AGENTS.md): 수업 방법, MP3 듣기 방식, 기록·동기화 규칙
- [1일차 학습 기록](days/day-001/LESSON.md): 배운 내용과 실제 답변·교정
- [1일차 복습 문제](days/day-001/REVIEW.md): 정답 없이 혼자 풀 문제
- [누적 어휘](VOCABULARY.md): 뜻과 문장, 읽기·듣기 확인 상태

일차는 실제 수업 순서를 따릅니다. 하루 쉬었다고 자동으로 진도를 넘기지 않습니다.
날짜는 한국 시간으로 기록합니다. 온라인 연결과 GitHub 인증이 되어 있으면 수업 후 변경사항을 커밋하고 업로드합니다.
다른 컴퓨터에서 시작할 때는 GitHub 최신 기록을 먼저 내려받습니다. 충돌이 있으면 내용을 보존하고 해결합니다.

## 한 달의 학습 방향

하루 30~45분 이상을 기준으로, 주 5회 새 학습과 1회 복습·평가를 권장합니다.

| 단계 | 중심 내용 |
|---|---|
| 1주 | 기본 동사, 주어·동사·목적어, 현재형 |
| 2주 | 과거형, 부정문·의문문, 시간·장소 |
| 3주 | can, must, if, because, before와 지시·조건·이유 |
| 4주 | 누적 복습, 짧은 대화·문단, 처음 보는 문제 |

실제 진도는 복습 결과에 맞춰 조정합니다. 점수 상승이나 특정 영어 수준 도달을 보장하지 않습니다.
